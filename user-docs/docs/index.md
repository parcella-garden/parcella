# Parcella documentation

Parcella is free, open-source software for running an allotment garden
association: members and parcels, work hours, water and electricity
meters, invoices, insurance, announcements and more, all in one place for
the board.

This guide walks you through every screen of the application: what you
see there, what each field and button does, and what happens to your
club's data when you save.
