# Instrukcje {#task-guides}

!!! note "Tłumaczenie maszynowe"
    Ta strona została przetłumaczona maszynowo z języka angielskiego i nie została jeszcze sprawdzona. Jeśli coś jest niejasne, obowiązuje wersja angielska (język zmienisz u góry).

Rozdziały o modułach opisują każdy ekran po kolei. Te instrukcje robią
odwrotnie: prowadzą jedno zadanie od początku do końca, przez wszystkie
ekrany, których dotyczy, w kolejności, w jakiej zarząd naprawdę je
wykonuje.

Każda instrukcja to numerowana lista kroków. Każdy krok podaje pozycję
menu, ekran i potrzebny przycisk. Jeśli chcesz dokładnie wiedzieć, do
czego służy pole, przejdź pod link do rozdziału o module na końcu
instrukcji.

| Instrukcja | Kiedy jej potrzebujesz |
|---|---|
| [Konfiguracja nowego stowarzyszenia](new-club-setup.md) | Parcella została właśnie zainstalowana i logujesz się po raz pierwszy. |
| [Import członków i działek](csv-import.md) | Listę członków, działek lub liczników prowadzisz już w arkuszu kalkulacyjnym i nie chcesz wpisywać wszystkiego jeszcze raz. |
| [Przyjęcie nowego członka](new-member.md) | Ktoś ubiegał się o ogród i zaraz go dostanie. |
| [Przekazanie działki](parcel-handover.md) | Dzierżawca składa wypowiedzenie, a działka przechodzi do kogoś nowego. |
| [Roczne fakturowanie](annual-invoicing.md) | Czas rozliczyć dzierżawę, wodę, prąd, ubezpieczenie i nieodpracowane godziny. |
| [Zbieranie odczytów liczników](meter-readings.md) | Coroczny obchód odczytów liczników wody i prądu. |
| [Organizacja terminu prac](work-session.md) | Planujesz dzień prac społecznych i chcesz śledzić, kto przyszedł. |

!!! tip "Nie wiesz, co oznacza jakieś słowo?"
    Pojęcia stowarzyszenia, takie jak [kaucja](../glossary.md#deposit),
    [dzierżawa](../glossary.md#tenancy) czy
    [seria faktur](../glossary.md#invoice-run), wyjaśnia
    [słowniczek](../glossary.md).

## Zanim zaczniesz {#before-you-start}

- Większość instrukcji wymaga prawa **zapisu** w module, w którym
  pracuje -- członkowie zarządu i administratorzy mają je wszędzie. Zob.
  [Role, grupy i uprawnienia](../getting-started/roles-and-permissions.md).
- Niektóre moduły są wyłączone w nowej instalacji (np. **Finanse**,
  **Ogłoszenia** i **Magazyn w chmurze**). Instrukcja mówi, gdy któregoś
  potrzebuje; zob.
  [Włączanie i wyłączanie modułów](../administration/modules.md).
- Przed większymi zmianami -- importem, fakturowaniem, przekazaniem
  działki -- najpierw pobierz kopię zapasową. Zob.
  [Kopia zapasowa i przywracanie](../administration/backup.md).
