# Anleitungen {#task-guides}

Die Modulkapitel beschreiben jede Seite einzeln. Diese Anleitungen machen es
umgekehrt: Sie folgen einer Aufgabe von Anfang bis Ende, über alle Seiten,
die sie berührt, in der Reihenfolge, in der ein Vorstand sie tatsächlich
erledigt.

Jede Anleitung ist eine nummerierte Liste von Schritten. Jeder Schritt nennt
den Menüeintrag, die Seite und die Schaltfläche, die du brauchst. Willst du
genau wissen, was ein Feld tut, folg dem Link zum Modulkapitel am Ende der
Anleitung.

| Anleitung | Wann du sie brauchst |
|---|---|
| [Einen neuen Verein einrichten](new-club-setup.md) | Parcella ist gerade installiert, und du meldest dich zum ersten Mal an. |
| [Mitglieder und Parzellen importieren](csv-import.md) | Du führst deine Mitglieder-, Parzellen- oder Zählerliste schon in einer Tabelle und willst nicht alles neu eintippen. |
| [Ein neues Mitglied aufnehmen](new-member.md) | Jemand hat sich um einen Garten beworben und bekommt gleich einen. |
| [Eine Parzelle übergeben](parcel-handover.md) | Ein Pächter kündigt, und die Parzelle geht an jemand Neues. |
| [Die Jahresrechnung erstellen](annual-invoicing.md) | Es ist Zeit, Pacht, Wasser, Strom, Versicherung und fehlende Arbeitsstunden abzurechnen. |
| [Zählerstände erfassen](meter-readings.md) | Die jährliche Runde zum Ablesen der Wasser- und Stromzähler. |
| [Einen Arbeitseinsatz organisieren](work-session.md) | Du planst einen gemeinsamen Arbeitstag und willst festhalten, wer gekommen ist. |

!!! tip "Unsicher, was ein Wort bedeutet?"
    Vereinsbegriffe wie [Kaution](../glossary.md#deposit),
    [Pachtverhältnis](../glossary.md#tenancy) oder
    [Rechnungslauf](../glossary.md#invoice-run) erklärt das
    [Glossar](../glossary.md).

## Bevor du anfängst {#before-you-start}

- Die meisten Anleitungen brauchen das Recht **Schreiben** für das Modul, in
  dem sie arbeiten -- Vorstandsmitglieder und Administratoren haben es
  überall. Siehe
  [Rollen, Gruppen und Rechte](../getting-started/roles-and-permissions.md).
- Manche Module sind in einer frischen Installation ausgeschaltet (zum
  Beispiel **Finanzen**, **Mitteilungen** und **Cloud-Speicher**). Eine
  Anleitung sagt dir, wenn sie eins braucht; siehe
  [Module ein- und ausschalten](../administration/modules.md).
- Lade vor größeren Änderungen -- einem Import, einem Rechnungslauf, einer
  Parzellenübergabe -- erst eine Sicherung herunter. Siehe
  [Backup und Wiederherstellung](../administration/backup.md).
