# Návody {#task-guides}

!!! note "Strojový překlad"
    Tato stránka byla strojově přeložena z angličtiny a dosud nebyla zkontrolována. Pokud je něco nejasné, platí anglická verze (jazyk přepnete nahoře).

Kapitoly o modulech popisují každou obrazovku zvlášť. Tyto návody dělají
opak: sledují jednu práci od začátku do konce, přes všechny obrazovky,
kterých se týká, v pořadí, v jakém ji výbor skutečně dělá.

Každý návod je číslovaný seznam kroků. Každý krok uvádí položku menu,
obrazovku a tlačítko, které potřebujete. Pokud chcete podrobně vědět, co
dělá některé pole, použijte odkaz na kapitolu o modulu na konci návodu.

| Návod | Kdy ho potřebujete |
|---|---|
| [Založení nového spolku](new-club-setup.md) | Parcella byla právě nainstalována a přihlašujete se poprvé. |
| [Import členů a parcel](csv-import.md) | Seznam členů, parcel nebo měřidel už vedete v tabulce a nechcete vše znovu přepisovat. |
| [Přijetí nového člena](new-member.md) | Někdo se přihlásil o zahrádku a brzy ji dostane. |
| [Předání parcely](parcel-handover.md) | Nájemce dal výpověď a parcela přechází na někoho nového. |
| [Roční vyúčtování](annual-invoicing.md) | Je čas vyúčtovat nájem, vodu, elektřinu, pojištění a neodpracované hodiny. |
| [Odečty měřidel](meter-readings.md) | Každoroční obchůzka s odečtem vodoměrů a elektroměrů. |
| [Organizace pracovní směny](work-session.md) | Plánujete společný pracovní den a chcete evidovat, kdo přišel. |

!!! tip "Nevíte, co nějaké slovo znamená?"
    Spolkové pojmy jako [kauce](../glossary.md#deposit),
    [nájem](../glossary.md#tenancy) nebo
    [vyúčtování](../glossary.md#invoice-run) jsou vysvětleny ve
    [slovníčku](../glossary.md).

## Než začnete {#before-you-start}

- Většina návodů potřebuje oprávnění k **zápisu** v modulu, se kterým
  pracují -- členové výboru a administrátoři ho mají všude. Viz
  [Role, skupiny a oprávnění](../getting-started/roles-and-permissions.md).
- Některé moduly jsou v nové instalaci vypnuté (například **Finance**,
  **Oznámení** a **Cloudové úložiště**). Návod vám řekne, když nějaký
  potřebuje; viz [Zapínání a vypínání modulů](../administration/modules.md).
- Před většími změnami -- importem, vyúčtováním, předáním parcely --
  si nejprve stáhněte zálohu. Viz
  [Zálohování a obnova](../administration/backup.md).
