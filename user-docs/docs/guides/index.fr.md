Les chapitres sur les modules décrivent chaque écran l'un après l'autre.
Ces guides font l'inverse : ils suivent une tâche du début à la fin, à
travers tous les écrans concernés, dans l'ordre où un bureau la réalise
réellement.

Chaque guide est une liste numérotée d'étapes. Chaque étape indique
l'entrée de menu, l'écran et le bouton dont vous avez besoin. Pour savoir
en détail à quoi sert un champ, suivez le lien vers le chapitre du module
à la fin du guide.

## Avant de commencer {#before-you-start}

- La plupart des guides demandent le droit d'**écriture** sur le module
  concerné -- les membres du bureau et les administrateurs l'ont partout.
  Voir [Rôles, groupes et droits](../getting-started/roles-and-permissions.md).
- Certains modules sont désactivés sur une nouvelle installation (par
  exemple **Finances**, **Annonces** et **Stockage cloud**). Un guide
  vous indique quand il en a besoin ; voir
  [Activer et désactiver les modules](../administration/modules.md).
- Avant des changements importants -- un import, une série de factures,
  une transmission de parcelle -- téléchargez d'abord une sauvegarde. Voir
  [Sauvegarde et restauration](../administration/backup.md).
