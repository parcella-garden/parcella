# Task guides

The module chapters describe every screen one at a time. These guides do
the opposite: they follow one job from start to finish, across all the
screens it touches, in the order a board actually does it.

Each guide is a numbered list of steps. Every step names the menu entry,
the screen and the button you need. If you want to know what a field
does in detail, follow the link to the module chapter at the end of the
guide.

| Guide | When you need it |
|---|---|
| [Setting up a new club](new-club-setup.md) | Parcella has just been installed and you log in for the first time. |
| [Importing members and parcels](csv-import.md) | You already keep your member list, parcel list or meter list in a spreadsheet and don't want to type it all in again. |
| [Welcoming a new member](new-member.md) | Someone applied for a garden and is about to get one. |
| [Handing over a parcel](parcel-handover.md) | A tenant gives notice and the parcel goes to someone new. |
| [Running the annual invoices](annual-invoicing.md) | It's time to bill lease, water, electricity, insurance and missed work hours. |
| [Collecting meter readings](meter-readings.md) | The yearly round of reading water and electricity meters. |
| [Organising a work session](work-session.md) | You plan a community work day and want to track who came. |

!!! tip "Not sure what a word means?"
    Club terms such as [deposit](../glossary.md#deposit),
    [tenancy](../glossary.md#tenancy) or
    [invoice run](../glossary.md#invoice-run) are explained in the
    [glossary](../glossary.md), with the German term where it helps.

## Before you start

- Most guides need **write** permission for the module they work in --
  board members and administrators have it everywhere. See
  [Roles, groups and permissions](../getting-started/roles-and-permissions.md).
- Some modules are switched off on a fresh installation (for example
  **Finances**, **Announcements** and **Cloud storage**). A guide tells
  you when it needs one; see
  [Turning modules on and off](../administration/modules.md).
- Before larger changes -- an import, an invoice run, a parcel
  handover -- download a backup first. See
  [Backup and restore](../administration/backup.md).
