# Ukázková data {#sample-data}

!!! note "Strojový překlad"
    Tato stránka byla strojově přeložena z angličtiny a dosud nebyla zkontrolována. Pokud je něco nejasné, platí anglická verze (jazyk přepnete nahoře).

Ukázková data naplní novou instalaci realistickými smyšlenými záznamy
ve všech modulech, takže si můžete Parcellu proklikat a vyzkoušet dřív,
než zadáte svůj skutečný spolek. Až skončíte, jedním kliknutím je zase
všechna odstraníte.

!!! info "Kdo to může používat"
    Jen administrátoři. Otevřete **Administrace → Ukázková data**.

![Ukázková data](../assets/screenshots/administration/sample-data.png)

## Co se přidá {#what-this-adds}

Levá karta uvádí, co se vytvoří:

- **Základ:** 6 členů, 5 zahrádek a jejich přidělení, včetně jedné
  společné domácnosti a jednoho bývalého nájemce.
- **Pracovní hodiny:** roční konfigurace, jedna proběhlá a jedna
  nadcházející pracovní směna s účastníky a několik úkolů.
- **Měření:** jeden vodoměr a jeden elektroměr s odečty za dva roky.
- **Pojištění:** roční konfigurace, balíčky pojištění majetku a krytí
  pro dvě parcely.
- **Podpora:** několik ukázkových konverzací helpdesku v různých stavech.
- **Žádosti o nákup:** jedna otevřená, jedna schválená a jedna zamítnutá
  žádost.
- **Kalendář:** několik proběhlých a nadcházejících akcí spolku.
- **Inventář:** kategorie, několik předmětů a jeden právě zapůjčený
  předmět.
- **Nástěnka úkolů:** několik karet rozložených do všech tří sloupců.
- **Finance:** několik ukázkových účetních kategorií.

Parcella si pamatuje každý záznam, který takto vytvořila. **Odstranit
veškerá ukázková data** smaže přesně tyto záznamy a nic, co jste zadali
sami. Uživatelské účty se nikdy nevytvářejí ani nemění.

Ukázková data se dostanou i do modulů, které jsou vypnuté; chcete-li si
je prohlédnout, modul zapněte.

## Přidání nebo odstranění {#add-or-remove}

Co ukazuje pravá karta, závisí na stavu vaší instalace:

| Situace | Co vidíte |
|---|---|
| Nová instalace, zatím žádní členové ani parcely | *Tato instalace vypadá jako nová -- zatím žádná data o členech ani parcelách.* a tlačítko **Přidat ukázková data**. Po potvrzení se data vytvoří (**Ukázková data byla přidána.**). |
| Ukázková data jsou přítomna | **Aktuálně jsou přítomna ukázková data:** s počtem pro každou oblast a tlačítko **Odstranit veškerá ukázková data**. Po potvrzení se smažou (**Veškerá ukázková data byla odstraněna.**). Nelze to vrátit zpět. |
| Už existují skuteční členové nebo parcely | Poznámka, že ukázková data lze přidat jen do nové instalace. Žádné tlačítko tu není. |

!!! warning "Před ostrým provozem je odstraňte"
    Nemíchejte ukázková data se skutečnými. Odstraňte je dřív, než
    začnete zadávat skutečné členy a parcely svého spolku -- jakmile
    existují skutečná data, ukázková už nelze znovu přidat a smyšlené
    záznamy byste museli rozlišovat ručně.
