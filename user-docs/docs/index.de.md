# Parcella-Handbuch

Parcella ist freie Open-Source-Software für die Verwaltung eines
Kleingartenvereins: Mitglieder und Parzellen, Arbeitsstunden, Wasser- und
Stromzähler, Rechnungen, Versicherungen, Mitteilungen und mehr, alles an
einem Ort für den Vorstand.

Dieses Handbuch führt Sie durch jede Seite der Anwendung: was Sie dort
sehen, was jedes Feld und jede Schaltfläche bewirkt und was beim Speichern
mit den Daten Ihres Vereins passiert.

<div class="grid cards" markdown>

-   :material-rocket-launch: **[Erste Schritte](getting-started/index.md)**

    Erste Anmeldung, Navigation, Rollen und Rechte, das Dashboard.

-   :material-view-grid: **[Module](modules/index.md)**

    Ein Kapitel je Bereich der Anwendung, Seite für Seite.

-   :material-format-list-checks: **[Anleitungen](guides/index.md)**

    Schritt für Schritt durch die Aufgaben, die ein Vorstand wirklich
    erledigt: die Jahresrechnung, eine Parzellenübergabe, einen
    Arbeitseinsatz.

-   :material-cog: **[Administration](administration/index.md)**

    Vereinseinstellungen, Benutzer und Gruppen, Integrationen, Backups.

</div>
