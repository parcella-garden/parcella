# Dokumentace Parcella {#parcella-documentation}

!!! note "Strojový překlad"
    Tato stránka byla strojově přeložena z angličtiny a dosud nebyla zkontrolována. Pokud je něco nejasné, platí anglická verze (jazyk přepnete nahoře).

Parcella je svobodný open-source software pro správu zahrádkářského
spolku: členové a parcely, pracovní hodiny, měřidla vody a elektřiny,
faktury, pojištění, oznámení a další, vše na jednom místě pro výbor.

Tato příručka vás provede každou obrazovkou aplikace: co na ní vidíte,
co dělá každé pole a tlačítko a co se stane s daty vašeho spolku, když
uložíte.

<div class="grid cards" markdown>

-   :material-rocket-launch: **[První kroky](getting-started/index.md)**

    První přihlášení, navigace, role a oprávnění, dashboard.

-   :material-view-grid: **[Moduly](modules/index.md)**

    Jedna kapitola pro každou oblast aplikace, obrazovku po obrazovce.

-   :material-format-list-checks: **[Návody](guides/index.md)**

    Krok za krokem úkoly, které výbor skutečně dělá: roční vyúčtování,
    předání parcely, pracovní směna.

-   :material-cog: **[Administrace](administration/index.md)**

    Nastavení spolku, uživatelé a skupiny, integrace, zálohy.

</div>

!!! question "Něco chybí nebo je špatně?"
    Zeptejte se v [komunitním fóru](https://forum.parcella.org), nebo
    použijte ikonu tužky v horní části kterékoli stránky a navrhněte
    opravu na GitHubu. Parcella je open source (AGPL-3.0), takže ji může
    vylepšovat kdokoli.

Hledáte instalaci, REST API nebo informace o tom, jak je Parcella
postavená? To najdete v
[dokumentaci pro vývojáře na GitHubu](https://github.com/parcella-garden/parcella/tree/main/docs).
