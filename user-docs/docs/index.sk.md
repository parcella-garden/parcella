# Dokumentácia Parcella {#parcella-documentation}

!!! note "Strojový preklad"
    Táto stránka bola strojovo preložená z angličtiny a zatiaľ nebola skontrolovaná. Ak je niečo nejasné, platí anglická verzia (jazyk prepnete hore).

Parcella je slobodný open-source softvér na správu záhradkárskeho
spolku: členovia a parcely, pracovné hodiny, meradlá vody a elektriny,
faktúry, poistenie, oznamy a ďalšie, všetko na jednom mieste pre výbor.

Táto príručka vás prevedie každou obrazovkou aplikácie: čo na nej
uvidíte, čo robí každé pole a tlačidlo a čo sa stane s dátami vášho
spolku, keď uložíte.

<div class="grid cards" markdown>

-   :material-rocket-launch: **[Prvé kroky](getting-started/index.md)**

    Prvé prihlásenie, navigácia, roly a oprávnenia, dashboard.

-   :material-view-grid: **[Moduly](modules/index.md)**

-   :material-format-list-checks: **[Návody](guides/index.md)**

-   :material-cog: **[Administrácia](administration/index.md)**

!!! question "Niečo chýba alebo je nesprávne?"
    Opýtajte sa v [komunitnom fóre](https://forum.parcella.org) alebo
    použite ikonu ceruzky v hornej časti ktorejkoľvek stránky a navrhnite
    opravu na GitHube. Parcella je open source (AGPL-3.0), takže ju môže
    vylepšovať ktokoľvek.

Hľadáte inštaláciu, REST API alebo to, ako je Parcella postavená? To
nájdete v [dokumentácii pre vývojárov na
GitHube](https://github.com/parcella-garden/parcella/tree/main/docs).
