# Dokumentacja Parcella {#parcella-documentation}

!!! note "Tłumaczenie maszynowe"
    Ta strona została przetłumaczona maszynowo z języka angielskiego i nie została jeszcze sprawdzona. Jeśli coś jest niejasne, obowiązuje wersja angielska (język zmienisz u góry).

Parcella to darmowe oprogramowanie open source do prowadzenia
stowarzyszenia ogrodów działkowych: członkowie i działki, prace
społeczne, liczniki wody i prądu, faktury, ubezpieczenia, ogłoszenia i
wiele więcej -- wszystko w jednym miejscu dla zarządu.

Ten przewodnik prowadzi przez każdy ekran aplikacji: co na nim widzisz,
do czego służy każde pole i przycisk oraz co dzieje się z danymi Twojego
stowarzyszenia po zapisaniu.

<div class="grid cards" markdown>

-   :material-rocket-launch: **[Pierwsze kroki](getting-started/index.md)**

-   :material-view-grid: **[Moduły](modules/index.md)**

-   :material-format-list-checks: **[Instrukcje](guides/index.md)**

!!! question "Czegoś brakuje lub coś jest nie tak?"
    Zapytaj na [forum społeczności](https://forum.parcella.org) albo użyj
    ikony ołówka u góry dowolnej strony, aby zaproponować poprawkę na
    GitHubie. Parcella jest open source (AGPL-3.0), więc każdy może pomóc
    ją ulepszać.

Szukasz instalacji, REST API albo informacji, jak zbudowana jest
Parcella? To znajdziesz w
[dokumentacji dla deweloperów na GitHubie](https://github.com/parcella-garden/parcella/tree/main/docs).
