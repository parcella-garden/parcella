# Pour les jardiniers : s'inscrire à une session de travail {#for-gardeners-signing-up-for-a-work-session}

!!! note "Traduction automatique"
    Cette page a été traduite automatiquement de l'anglais et n'a pas encore été relue. En cas de doute, la version anglaise fait foi (changez de langue en haut de la page).

Cette page s'adresse aux jardiniers d'une association qui utilise
Parcella. Votre bureau peut y renvoyer depuis le site web de
l'association.

!!! info "En bref"
    Vous n'avez besoin ni d'un compte ni d'un mot de passe. Vous vous
    inscrivez sur le site web de votre association avec votre **numéro
    de parcelle**. Le bureau voit ensuite votre inscription, et vous
    recevez un e-mail de confirmation.

## Où s'inscrire {#where-to-sign-up}

Le site web de votre association a une page avec un formulaire
d'inscription aux sessions de travail (parfois appelées « journées de
travail » ou « travaux collectifs »). Demandez à votre bureau où la
trouver si vous n'êtes pas sûr.

Le formulaire ne liste que les sessions qui :

- n'ont pas encore eu lieu,
- ont encore des places libres (le nombre de places restantes peut être
  affiché à côté de la date), et
- sont encore ouvertes aux inscriptions -- certaines sessions ferment
  un jour ou plus avant leur début.

Si une session que vous attendiez manque, elle est probablement complète
ou fermée. Contactez directement votre bureau.

## Remplir le formulaire {#filling-in-the-form}

L'apparence exacte dépend du site web de votre association. En général
vous voyez :

| Champ | Ce qu'il faut saisir |
|---|---|
| **Nom** | Facultatif, mais utile : votre nom tel que l'association le connaît. Important si plusieurs personnes partagent votre parcelle. |
| **Numéro de parcelle** | Obligatoire. Choisissez votre numéro de parcelle dans la liste. |
| Sessions | Cochez une ou plusieurs sessions auxquelles vous voulez participer. |
| **Remarques** | Facultatif. Tout ce que le bureau doit savoir, par ex. « Je ne peux venir que jusqu'à midi ». |

Cliquez ensuite sur **S'inscrire**.

!!! note "Pourquoi seulement un numéro de parcelle ?"
    Le site web n'affiche jamais qui loue quelle parcelle -- c'est
    privé. Parcella déduit qui vous êtes à partir du numéro de parcelle
    et du nom que vous saisissez.

## Et ensuite ? {#what-happens-next}

Un message s'affiche sur le site web :

- **Merci, votre inscription a bien été reçue.** -- c'est fait.
- Si certaines des sessions cochées sont devenues complètes ou fermées
  entre-temps, le message l'indique. Les autres sessions sont réservées.
- Si quelque chose n'a pas fonctionné (numéro de parcelle inconnu,
  aucune session cochée, trop de tentatives en peu de temps), le message
  vous dit quoi faire.

En coulisses :

- Si votre nom correspond à l'une des personnes de votre parcelle,
  **vous seul** êtes inscrit.
- Si vous avez laissé le nom vide, ou s'il ne correspond pas clairement,
  **toutes les personnes de votre parcelle** sont inscrites, et le bureau
  est invité à vérifier. Pas d'inquiétude -- le bureau retire ceux qui
  ne viennent pas.
- S'inscrire deux fois à la même session ne crée pas de doublon.

## Les e-mails que vous recevez {#the-e-mails-you-receive}

Après une inscription réussie, chaque personne inscrite reçoit un
**e-mail de confirmation**, un par session. L'objet est
« RE : votre inscription à la journée de travail du » suivi de la date
(dans la langue de votre association). Il contient un court texte de
votre bureau ainsi que le titre, la date et l'heure de la session. Si
vous seul avez été inscrit, vos remarques sont aussi citées.

Bon à savoir :

- L'e-mail part à l'adresse **que l'association a enregistrée pour
  vous**, pas à une adresse saisie dans le formulaire. Si vous ne le
  recevez pas, l'association n'a peut-être pas votre adresse e-mail
  actuelle -- prévenez le bureau.
- Si personne sur votre parcelle n'a d'adresse e-mail enregistrée,
  personne ne reçoit de confirmation. L'inscription compte quand même.
- Votre bureau peut désactiver les e-mails de confirmation.

Il n'y a pas d'e-mail pour annuler. **Pour annuler ou modifier une
inscription, contactez votre bureau** -- par téléphone, par e-mail ou
via le formulaire de contact de l'association.

## Autres formulaires sur le site de votre association {#other-forms-on-your-clubs-website}

Votre association peut aussi utiliser Parcella pour d'autres formulaires
de son site web :

- **Formulaire de contact** -- votre message arrive directement dans la
  boîte de réception du support du bureau. Vous recevez la réponse par
  e-mail depuis celle-ci.
- **Candidature à une parcelle** -- pour les personnes qui aimeraient un
  jardin. Le bureau voit votre candidature et vous contacte.

## Des questions ? {#questions}

Contactez le bureau de votre association. Ce guide est général ; le site
web de votre association et ses règles pour les sessions de travail
priment.
